## List of public-facing projects

### Tandem Repeats

- **[trexplorer.broadinstitute.org](https://trexplorer.broadinstitute.org)**: An online portal for exploring and visualizing tandem repeats (TRs) genome-wide. It enables searching, sorting, and exporting TRs based on a wide range of annotations including population allele frequencies from short-read and long-read datasets, genic and chromosomal regions, published TR functions (expression, splicing, ...), association study results, and many others. [[code](https://github.com/broadinstitute/TRExplorer)] [[publication](https://pubmed.ncbi.nlm.nih.gov/42025159/)]<br /><b>Role:</b> Solo developer and maintainer. Created and released initial version in <b>2025</b>.<br /><b>Users:</b> {{weekly_visitors:trexplorer.broadinstitute.org}}, {{google_scholar_citations:Defining a tandem repeat catalog and variation clusters for genome-wide analyses and population databases}}
- **[trexplorer-catalog](https://github.com/broadinstitute/trexplorer-catalog/blob/main/README.md)**: TR catalog and variation clusters for genome-wide analyses and population databases. [[code](https://github.com/broadinstitute/trexplorer-catalog)] [[publication](https://pubmed.ncbi.nlm.nih.gov/42025159/)]<br /><b>Role:</b> Primary developer and maintainer. Created and released initial version in <b>2024</b>.<br /><b>Users:</b> {{github_stars:broadinstitute/trexplorer-catalog}}, {{google_scholar_citations:Defining a tandem repeat catalog and variation clusters for genome-wide analyses and population databases}}
- **[ExpansionHunter (bw2 fork)](https://github.com/bw2/ExpansionHunter/blob/master/README.md)**: A fork of [Illumina/ExpansionHunter](https://github.com/Illumina/ExpansionHunter) that adds substantial new features and optimizations including optimized-streaming mode, motif composition analysis, allele quality scores, and others. [[code](https://github.com/bw2/ExpansionHunter)]<br /><b>Role:</b> Solo developer and maintainer of the fork. Started adding new features in <b>2024</b>.<br /><b>Users:</b> {{github_stars:bw2/ExpansionHunter}}
- **[str-analysis](https://github.com/broadinstitute/str-analysis/blob/main/README.md)**: Scripts and utilities for analyzing tandem repeats. [[code](https://github.com/broadinstitute/str-analysis)]<br /><b>Role:</b> Solo developer and maintainer. Created and released initial version in <b>2021</b>.<br /><b>Users:</b> {{github_stars:broadinstitute/str-analysis}}
- **[str-truth-set](https://github.com/broadinstitute/str-truth-set/blob/main/README.md)**: Genome-wide TR truth set based on the Synthetic Diploid Benchmark (Li et al. 2018). [[code](https://github.com/broadinstitute/str-truth-set)] [[publication](https://pubmed.ncbi.nlm.nih.gov/37214979/)]<br /><b>Role:</b> Solo developer and maintainer. Created and released initial version in <b>2022</b>.<br /><b>Users:</b> {{google_scholar_citations:Insights from a genome-wide truth set of tandem repeat variation}}
- **[str-truth-set-v2](https://github.com/broadinstitute/str-truth-set-v2/blob/main/README.md)**: v2.0 of the TR truth set (now based on 321 haplotype-resolved assemblies), along with a [tool benchmark viewer](https://broadinstitute.github.io/str-truth-set-v2/tool_comparison_viewer.html). [[code](https://github.com/broadinstitute/str-truth-set-v2)]<br /><b>Role:</b> Solo developer and maintainer. Created and released initial version in <b>2023</b>.
- **[TRails](https://github.com/broadinstitute/TRails/blob/main/README.md)**: A local, interactive app for prioritizing tandem repeat outlier expansions in rare disease callsets. [[code](https://github.com/broadinstitute/TRails)]<br /><b>Role:</b> Solo developer and maintainer. Created and released initial version in <b>2026</b>.
- **[colab-repeat-finder](https://github.com/broadinstitute/colab-repeat-finder/blob/main/README.md)**: A tool for finding perfect repeats in the reference genome that span more than M base pairs and/or N repeats. [[code](https://github.com/broadinstitute/colab-repeat-finder)]<br /><b>Role:</b> Solo developer and maintainer. Created and released initial version in <b>2024</b>.
- **[StrPileups](https://broadinstitute.github.io/StrPileups/)**: ExpansionHunter genotypes, REViewer read visualizations, and PCR truth data for 133 individuals at 14 known pathogenic STR loci. [[code](https://github.com/broadinstitute/StrPileups)] [[publication](https://pubmed.ncbi.nlm.nih.gov/35948990/)]<br /><b>Role:</b> Created and released initial version in <b>2021</b>.

### Other Rare Disease and Genomics Projects

- **[sma-finder](https://github.com/broadinstitute/sma-finder/blob/main/README.md)**: A tool for diagnosing spinal muscular atrophy (SMA) in exome, genome, or targeted sequencing data. [[code](https://github.com/broadinstitute/sma-finder)] [[publication](https://pubmed.ncbi.nlm.nih.gov/39670433/)]<br /><b>Role:</b> Primary developer and maintainer. Created and released initial version in <b>2022</b>.<br /><b>Users:</b> {{github_stars:broadinstitute/sma-finder}}, {{google_scholar_citations:Diagnosing missed cases of spinal muscular atrophy in genome, exome, and panel sequencing data sets}}
- **[gnomad.broadinstitute.org](https://gnomad.broadinstitute.org)**: Genome Aggregation Database browser. [[code](https://github.com/broadinstitute/gnomad-browser)] [[publication](https://pubmed.ncbi.nlm.nih.gov/32461654/)]<br /><b>Role:</b> Oversaw development, maintenance and hiring for the gnomAD browser <b>2015</b> to <b>2020</b>. Contributed the [read visualization pipeline](https://github.com/broadinstitute/gnomad-readviz) in <b>2019</b>, and the [ExpansionHunter callset for known disease-associated TR loci](https://gnomad.broadinstitute.org/news/2022-01-the-addition-of-short-tandem-repeat-calls-to-gnomad/) in <b>2022</b>.<br /><b>Users:</b> 167,405 weekly visitors<!-- fixed by hand: the average over Aug 24 to Sep 27, 2026, before bots swamped gnomAD's Google Analytics numbers -->, {{github_stars:broadinstitute/gnomad-browser}}, {{google_scholar_citations:The mutational constraint spectrum quantified from variation in 141,456 humans}}
- **[spliceailookup.broadinstitute.org](https://spliceailookup.broadinstitute.org)**: Website for running SpliceAI, Pangolin, and SAI-10k prediction models on variants of interest, visualizing results, while also checking other variant effect predictor scores. [[code](https://github.com/broadinstitute/SpliceAI-lookup)]<br /><b>Role:</b> Solo developer and maintainer. Created and released initial version in <b>2020</b>.<br /><b>Users:</b> {{weekly_visitors:spliceailookup.broadinstitute.org}}, {{github_stars:broadinstitute/SpliceAI-lookup}}, [658 citations](https://scholar.google.com/scholar?q=%22spliceailookup.broadinstitute.org%22)
- **[liftover.broadinstitute.org](https://liftover.broadinstitute.org)**: A user-friendly genomic liftover interface for variants, positions, or intervals. [[code](https://github.com/broadinstitute/liftover)]<br /><b>Role:</b> Solo developer and maintainer. Created and released initial version in <b>2020</b>.<br /><b>Users:</b> {{weekly_visitors:liftover.broadinstitute.org}}
- **[seqr.broadinstitute.org](https://seqr.broadinstitute.org)**: Web-based interactive analysis and variant prioritization tool for rare disease genomic datasets including genomes, exomes, and RNA-seq. [[code](https://github.com/broadinstitute/seqr)] [[publication](https://pubmed.ncbi.nlm.nih.gov/35266241/)]<br /><b>Role:</b> Core developer and maintainer from <b>2015</b> to <b>2020</b>. Also, oversaw hiring.<br /><b>Users:</b> {{weekly_visitors:seqr.broadinstitute.org}}, {{github_stars:broadinstitute/seqr}}, {{google_scholar_citations:seqr: A web-based analysis and collaboration tool for rare disease genomics}}
- **[genelookup.broadinstitute.org](https://genelookup.broadinstitute.org)**: Website that aggregates information about gene-disease relationships from OMIM, ClinGen, PanelApp UK, and over 10 other sources, provides an AI summary of the phenotype, and makes the information easier to search, compare, and export. [[code](https://github.com/broadinstitute/gene-lookup)]<br /><b>Role:</b> Solo developer and maintainer. Created and released initial version in <b>2025</b>.<br /><b>Users:</b> {{weekly_visitors:genelookup.broadinstitute.org}}
- **[tgg-viewer.broadinstitute.org](https://tgg-viewer.broadinstitute.org)**: Web app for visualizing splice junctions, copy number variation, and other sequencing data using IGV.js. [[code](https://github.com/broadinstitute/tgg-viewer)]<br /><b>Role:</b> Maintainer. Created and released initial version in <b>2019</b>.
- **[phenotype-driven-analysis](https://github.com/broadinstitute/phenotype-driven-analysis/blob/main/README.md)**: Pipeline for phenotype-driven analysis of rare disease cases using the LIRICAL tool. [[code](https://github.com/broadinstitute/phenotype-driven-analysis)] [[blog post 1](https://bw2.github.io/2022-05-04-phenotype-based-prioritization.html)] [[blog post 2](https://bw2.github.io/2022-06-01-phenotype-based-prioritization2-LIRICAL-vs-exomiser.html)]<br /><b>Role:</b> Created and released initial version in <b>2022</b>.

### General Software

- **[ConfigArgParse](https://github.com/bw2/ConfigArgParse/blob/master/README.md)**: Drop-in replacement for Python's argparse that adds support for config files and environment variables. [[code](https://github.com/bw2/ConfigArgParse)]<br /><b>Role:</b> Primary developer and maintainer. Created and released initial version in <b>2014</b>.<br /><b>Users:</b> {{github_stars:bw2/ConfigArgParse}}, [used by 25,935 GitHub repositories](https://github.com/bw2/ConfigArgParse/network/dependents)
- **[flipbook](https://github.com/broadinstitute/flipbook/blob/main/README.md)**: Quickly flip through images in a local directory and record notes or answer questions about each one. [[code](https://github.com/broadinstitute/flipbook)] [[publication](https://pubmed.ncbi.nlm.nih.gov/35948990/)]<br /><b>Role:</b> Solo developer and maintainer. Created and released initial version in <b>2021</b>.<br /><b>Users:</b> {{github_stars:broadinstitute/flipbook}}
- **[step-pipeline](https://github.com/bw2/step-pipeline/blob/main/README.md)**: A thin wrapper around the [Hail Batch](https://hail.is/docs/batch/index.html) compute cluster API. It adds features like skipping steps whose output files already exist, extra options for localizing files, and visualizations of pipeline DAGs. [[code](https://github.com/bw2/step-pipeline)]<br /><b>Role:</b> Solo developer and maintainer. Created and released initial version in <b>2021</b>.

### AI Coding Agents

- **[agent-command-tab](https://github.com/bw2/agent-command-tab/blob/main/README.md)**: A macOS menu bar app that lists the iTerm2 and tmux tabs where AI coding agents (Claude Code, Codex CLI, and others) are running, and shows what each one is doing. [[code](https://github.com/bw2/agent-command-tab)]<br /><b>Role:</b> Solo developer and maintainer. Created and released initial version in <b>2026</b>.
- **[claude-code-review-skill](https://github.com/bw2/claude-code-review-skill/blob/main/README.md)**: Claude Code skill that runs code review with Opus and Sonnet (plus, optionally, Google Antigravity), with blind peer validation and confidence-scored findings. [[code](https://github.com/bw2/claude-code-review-skill)]<br /><b>Role:</b> Solo developer and maintainer. Created and released initial version in <b>2026</b>.
- **[claude-code-session-recall](https://github.com/bw2/claude-code-session-recall/blob/main/README.md)**: Claude Code skill that searches and summarizes recent Claude Code sessions for the current directory. [[code](https://github.com/bw2/claude-code-session-recall)]<br /><b>Role:</b> Solo developer and maintainer. Created and released initial version in <b>2026</b>.
- **[claude-error-patterns](https://github.com/bw2/claude-error-patterns/blob/main/README.md)**: Claude Code plugin that analyzes session logs for recurring error patterns and wheel-spinning loops. [[code](https://github.com/bw2/claude-error-patterns)]<br /><b>Role:</b> Solo developer and maintainer. Created and released initial version in <b>2026</b>.
