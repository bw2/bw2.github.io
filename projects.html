List of public-facing projects

Tandem Repeats

  • trexplorer.broadinstitute.org: An online portal for exploring and visualizing tandem repeats (TRs) genome-wide. It enables searching, sorting, and exporting TRs based on a wide range of annotations including population allele frequencies from short-read and long-read datasets, genic and chromosomal regions, published TR functions (expression, splicing, ...), association study results, and many others. [code] [publication]
    Role: Solo developer and maintainer. Created and released initial version in 2025.
    Users: 27 citations
  • trexplorer-catalog: TR catalog and variation clusters for genome-wide analyses and population databases. [code] [publication]
    Role: Primary developer and maintainer. Created and released initial version in 2024.
    Users: 20 GitHub stars, 27 citations
  • ExpansionHunter (bw2 fork): A fork of Illumina/ExpansionHunter that adds substantial new features and optimizations including optimized-streaming mode, motif composition analysis, allele quality scores, and others. [code]
    Role: Solo developer and maintainer of the fork. Started adding new features in 2024.
    Users: 20 GitHub stars
  • str-analysis: Scripts and utilities for analyzing tandem repeats. [code]
    Role: Solo developer and maintainer. Created and released initial version in 2021.
    Users: 53 GitHub stars
  • str-truth-set: Genome-wide TR truth set based on the Synthetic Diploid Benchmark (Li et al. 2018). [code] [publication]
    Role: Solo developer and maintainer. Created and released initial version in 2022.
    Users: 16 citations
  • str-truth-set-v2: v2.0 of the TR truth set (now based on 321 haplotype-resolved assemblies), along with a tool benchmark viewer. [code]
    Role: Solo developer and maintainer. Created and released initial version in 2023.
  • TRails: A local, interactive app for prioritizing tandem repeat outlier expansions in rare disease callsets. [code]
    Role: Solo developer and maintainer. Created and released initial version in 2026.
  • colab-repeat-finder: A tool for finding perfect repeats in the reference genome that span more than M base pairs and/or N repeats. [code]
    Role: Solo developer and maintainer. Created and released initial version in 2024.
  • StrPileups: ExpansionHunter genotypes, REViewer read visualizations, and PCR truth data for 133 individuals at 14 known pathogenic STR loci. [code] [publication]
    Role: Created and released initial version in 2021.

Other Rare Disease and Genomics Projects

  • sma-finder: A tool for diagnosing spinal muscular atrophy (SMA) in exome, genome, or targeted sequencing data. [code] [publication]
    Role: Primary developer and maintainer. Created and released initial version in 2022.
    Users: 15 GitHub stars, 12 citations
  • gnomad.broadinstitute.org: Genome Aggregation Database browser. [code] [publication]
    Role: Oversaw development, maintenance and hiring for the gnomAD browser 2015 to 2020. Contributed the read visualization pipeline in 2019, and the ExpansionHunter callset for known disease-associated TR loci in 2022.
    Users: 167,405 weekly visitors, 92 GitHub stars, 11,947 citations
  • spliceailookup.broadinstitute.org: Website for running SpliceAI, Pangolin, and SAI-10k prediction models on variants of interest, visualizing results, while also checking other variant effect predictor scores. [code]
    Role: Solo developer and maintainer. Created and released initial version in 2020.
    Users: 8,087 weekly visitors, 35 GitHub stars, 658 citations
  • liftover.broadinstitute.org: A user-friendly genomic liftover interface for variants, positions, or intervals. [code]
    Role: Solo developer and maintainer. Created and released initial version in 2020.
    Users: 1,269 weekly visitors
  • seqr.broadinstitute.org: Web-based interactive analysis and variant prioritization tool for rare disease genomic datasets including genomes, exomes, and RNA-seq. [code] [publication]
    Role: Core developer, maintainer, and hiring manager from 2015 to 2020.
    Users: 221 GitHub stars, 149 citations
  • genelookup.broadinstitute.org: Website that aggregates information about gene-disease relationships from OMIM, ClinGen, PanelApp UK, and over 10 other sources, provides an AI summary of the phenotype, and makes the information easier to search, compare, and export. [code]
    Role: Solo developer and maintainer. Created and released initial version in 2025.
  • tgg-viewer.broadinstitute.org: Web app for visualizing splice junctions, copy number variation, and other sequencing data using IGV.js. [code]
    Role: Maintainer. Created and released initial version in 2019.
  • phenotype-driven-analysis: Pipeline for phenotype-driven analysis of rare disease cases using the LIRICAL tool. [code] [blog post 1] [blog post 2]
    Role: Created and released initial version in 2022.

General Software

  • ConfigArgParse: Drop-in replacement for Python's argparse that adds support for config files and environment variables. [code]
    Role: Primary developer and maintainer. Created and released initial version in 2014.
    Users: 761 GitHub stars, used by 25,935 GitHub repositories
  • flipbook: Quickly flip through images in a local directory and record notes or answer questions about each one. [code] [publication]
    Role: Solo developer and maintainer. Created and released initial version in 2021.
    Users: 23 GitHub stars
  • step-pipeline: A thin wrapper around the Hail Batch compute cluster API. It adds features like skipping steps whose output files already exist, extra options for localizing files, and visualizations of pipeline DAGs. [code]
    Role: Solo developer and maintainer. Created and released initial version in 2021.

AI Coding Agents

  • agent-command-tab: A macOS menu bar app that lists the iTerm2 and tmux tabs where AI coding agents (Claude Code, Codex CLI, and others) are running, and shows what each one is doing. [code]
    Role: Solo developer and maintainer. Created and released initial version in 2026.
  • claude-code-review-skill: Claude Code skill that runs code review with Opus and Sonnet (plus, optionally, Google Antigravity), with blind peer validation and confidence-scored findings. [code]
    Role: Solo developer and maintainer. Created and released initial version in 2026.
  • claude-code-session-recall: Claude Code skill that searches and summarizes recent Claude Code sessions for the current directory. [code]
    Role: Solo developer and maintainer. Created and released initial version in 2026.
  • claude-error-patterns: Claude Code plugin that analyzes session logs for recurring error patterns and wheel-spinning loops. [code]
    Role: Solo developer and maintainer. Created and released initial version in 2026.
